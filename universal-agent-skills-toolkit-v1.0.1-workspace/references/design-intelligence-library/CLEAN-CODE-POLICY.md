# Kebijakan Kode Bersih, Anti-Iklan & Anti-Watermark AI

Dokumen ini memuat aturan operasional wajib untuk seluruh proses kurasi, integrasi, dan kompilasi kode di dalam ekosistem AGY sesuai Bagian 16: Mandatory Clean Code, No-Ads & No-AI-Watermark Policy.

---

## 1. Daftar Konten yang Dilarang Keras (Prohibited Injected Content)

Seluruh kode yang masuk ke dalam produksi dilarang menyertakan:
1. Badge, logo, stiker, atau watermark visual buatan AI.
2. Label promosi seperti *"Made with AI"*, *"Built with AI"*, *"Generated by AI"*, atau sejenisnya.
3. Iklan vendor, spanduk komersial, konten bersponsor, atau pop-up promosi.
4. Tautan balik (*backlinks*) pihak ketiga atau tautan rujukan yang tidak diminta oleh pengguna.
5. Piksel pelacak tersembunyi, skrip analitik terselubung, atau telemetri runtime.
6. Permintaan jaringan keluar (*external network requests*) yang tidak terdokumentasi secara eksplisit.
7. Elemen atribusi vendor yang dipaksakan masuk ke antarmuka pengguna situs web.
8. Metadata tersembunyi, komentar promosi, atau elemen SVG yang membawa muatan promosi komersial.

---

## 2. Empat Dimensi Kebersihan Produksi

Setiap sumber atau integrasi dievaluasi dalam 4 dimensi:

1. **Source-Code Cleanliness**:
   - Kode sumber mentah tidak memuat skrip terobfuskasi, string base64 tersembunyi, atau atribut data promosi.
2. **Dependency Cleanliness**:
   - File `package.json` bebas dari modul pelacak atau paket malware; tidak mengeksekusi lifecycle scripts berbahaya pada `postinstall`.
3. **Build-Time Cleanliness**:
   - Proses kompilasi (misalnya `vite build` atau `npm run build`) tidak menginjeksi tag pelacak atau skrip pihak ketiga ke berkas output HTML/JS.
4. **Production-Output Cleanliness**:
   - Inspeksi DOM di browser nyata membuktikan bahwa halaman yang dirender 100% bersih, responsif, dan hanya memuat antarmuka yang diminta pengguna.

## 4. Prosedur Verifikasi Headless DOM (Playwright)

Sebelum sebuah proyek dinyatakan siap terbit (*production-ready*), verifikasi otomatis dijalankan via Playwright MCP untuk memeriksa:
1. Pengecekan teks terlarang di seluruh DOM:
   - Mencari pola: `Built with`, `Made in`, `Powered by`, `Spline`, `Framer`.
2. Pengecekan koneksi jaringan:
   - Memastikan tidak ada request keluar ke endpoint analitik atau CDN eksternal yang tidak terdokumentasi.
3. Pengecekan elemen tersembunyi:
   - Memastikan tidak ada elemen dengan `opacity: 0` atau `position: absolute; left: -9999px` yang menyembunyikan tautan promosi atau piksel pelacak.
